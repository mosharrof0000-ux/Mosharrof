# Mosharrof Autonomous Operating Model

- **Main is the protected live source.**
- Agents work only on isolated branches.
- Every proposed change must pass automated tests.
- Promotion occurs through a Pull Request and controlled auto-merge.
- GitHub Pages deploys from main only.
- Post-deployment health check must pass.
- Scheduled autonomous maintenance runs every 6 hours.
- User feature requests can enter through the `[AUTO]` issue channel.
- Deletion of repository/project/critical infrastructure is not part of the autonomous workflow.
