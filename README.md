# Mosharrof

**Mosharrof Karim — Intelligent Entity and AI Brain Architecture**

Mosharrof is being built as a model-agnostic intelligent entity ecosystem.

## Foundation

- Core identity and entity registry
- Separate responsibility and permission boundaries
- Model adapter strategy
- Explicit memory and audit concepts
- Permanent denial of DELETE and destructive operations
- Automated tests
- GitHub Pages project interface

## Repository structure

- `src/core/` — runtime contracts
- `entities/` — entity definitions
- `brains/` — brain/model adapters
- `policies/` — capability and safety policy
- `tools/` — tools
- `memory/` — memory
- `audit/` — audit
- `docs/` — machine-readable project knowledge
- `web/` — web interface
- `tests/` — tests

## Live project

https://mosharrof0000-ux.github.io/Mosharrof/

The current release is a foundation interface. A production AI model runtime is not claimed until a model adapter is connected and verified.

## Governance

Changes should follow:

**Create → Review → Test → Approve → Merge → Document**

`DELETE` and destructive operations remain permanently denied.
