# Mosharrof

**Mosharrof Karim — Intelligent Entity and AI Brain Architecture**

Mosharrof is the root coordination project for an extensible ecosystem of independent intelligent entities.

## Foundation rules
- Each meaningful component is an independent Entity with its own responsibility.
- Each Entity may use a replaceable Brain/Model adapter.
- Actual capability is constrained by Identity, Permission, Policy and Scope.
- Delete and destructive operations are permanently blocked.
- Changes must be auditable, versioned, tested and documented.
- Existing projects are connected as Tools/Projects; they are not silently rewritten.

## Repository map
- core/ — machine-readable project and entity definitions.
- src/core/ — runtime foundation components.
- src/entities/ — future independent entity implementations.
- src/tools/ — approved tools.
- policies/ — permissions and safety rules.
- memory/ — memory schemas and contracts.
- audit/ — change and decision records.
- tests/ — deterministic tests.
- web/ — GitHub Pages interface.

## Live site
The GitHub Pages deployment publishes only web/ and contains no runtime secrets.
