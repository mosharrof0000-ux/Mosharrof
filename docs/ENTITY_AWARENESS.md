# Mosharrof Entity Awareness

Mosharrof now has an explicit operational-awareness layer for every registered entity. Here “চৈতন্য” means software self-awareness: an entity can identify and report its identity, responsibility, state, health, permissions and audit boundary. It is not a claim of human-like consciousness.

Each entity is checked for identity, brain, responsibility, memory, permissions, policy, tools, communication, state, health, audit and version.

Awareness does not grant unlimited power. Delete, destructive operations, secret exposure, permission escalation and direct main writes remain denied.

If an entity is degraded, the system reports the missing awareness facet. Automatic repair is disabled; any repair must be scoped, authorized and pass the existing isolated-branch, test and protected-PR process.

Verification command: python3 scripts/entity_awareness.py
