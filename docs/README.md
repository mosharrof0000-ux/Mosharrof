# Mosharrof Project Map

Read in this order:

1. `PROJECT_MANIFEST.json` — what Mosharrof is and how it boots.
2. `entities/ENTITY_REGISTRY.json` — every entity and its responsibility.
3. `brains/BRAIN_REGISTRY.json` — every brain and model adapter.
4. `permissions/PERMISSION_REGISTRY.json` — capability boundaries.
5. `policy/NO_DELETE_POLICY.json` — hard safety rules.
6. `communication/COMMUNICATION_CONTRACT.json` — entity messaging contract.
7. `audit/AUDIT_CONTRACT.json` — traceability contract.

A new AI should read this map before changing the project.
