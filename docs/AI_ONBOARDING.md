# Mosharrof AI Onboarding

Read in this order:

1. `config/project_manifest.json`
2. `config/entity_registry.json`
3. `config/model_registry.json`
4. `config/policy.json`
5. `config/permission_profiles.json`
6. `policies/CORE_POLICY.md`
7. `docs/ARCHITECTURE.md`

Then open only the entity folder relevant to the assigned responsibility.

Capability is bounded by identity, brain, permission, policy, scope and tools. A stronger model does not gain authority automatically.

DELETE, destructive operations and scope escape are permanently blocked. Activation without tests is blocked.

Al-Quran Research is an independent external project until explicit integration.
