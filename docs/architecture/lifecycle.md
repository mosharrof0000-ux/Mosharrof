# Mosharrof Entity Lifecycle

1. Define identity.
2. Define responsibility and scope.
3. Assign a brain interface and model adapter.
4. Attach memory and state.
5. Assign the minimum required permissions.
6. Attach tools and communication channels.
7. Register the entity in the Entity Registry.
8. Run automated tests.
9. Review the audit result.
10. Activate only after verification.

## Permanent boundary

DELETE and destructive operations are denied by the core policy. A temporary permission may expand a non-destructive capability only for a specific task, with an audit record and explicit revocation.
