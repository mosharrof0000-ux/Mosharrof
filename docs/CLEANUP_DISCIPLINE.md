# Cleanup Discipline System

> **কাজ শেষ ≠ কাজ সম্পূর্ণ। পরিষ্কার করে আসা পর্যন্ত কাজ অসম্পূর্ণ।**

যে কেউ (মানুষ, Grok, ChatGPT, বা অন্য এজেন্ট) এই প্রজেক্টে কাজ করলে 
কাজ শেষে অবশ্যই নিচের নিয়ম মেনে পরিষ্কার করে আসবে।

এটা অস্থায়ী পরামর্শ নয় — এটা **স্থায়ী শৃঙ্খলা**।

---

## 1. কেন দরকার

- আধা-আধা ব্রাঞ্চ ও ফাইল জমলে সিস্টেম বোঝা কঠিন হয়
- পরের কাজকারী বিভ্রান্ত হয়
- ডিপ্লয় ও টেস্ট ভেঙে যায়
- মোশাররফের “সভ্যতা” নোংরা হয়ে যায়

পরিষ্কার রিপো = সম্মান।

---

## 2. কাজ শেষে বাধ্যতামূলক চেকলিস্ট

প্রত্যেক কাজের শেষে নিচের সবগুলো পূরণ করতে হবে:

### A. কোড ও ফাইল
- [ ] শুধু প্রয়োজনীয় ফাইল main-এ আছে
- [ ] ডিবাগ / temporary ফাইল নেই (`*.tmp`, `debug_*`, `scratch_*`)
- [ ] অপ্রয়োজনীয় বড় লগ বা ডাটা কমিট হয়নি

### B. ব্রাঞ্চ
- [ ] কাজের ফিচার ব্রাঞ্চ মার্জ হয়ে গেছে
- [ ] মার্জ হওয়া পুরনো ফিচার ব্রাঞ্চ ডিলিট করা হয়েছে (বা আর্কাইভ নীতি অনুসারে)
- [ ] `main` ছাড়া অপ্রয়োজনীয় ওপেন ব্রাঞ্চ জমে নেই

### C. টেস্ট ও ডিপ্লয়
- [ ] `pytest` পাস
- [ ] ডিপ্লয় ওয়ার্কফ্লো সবুজ (Pages লাইভ হলে)
- [ ] লাইভ সাইটে ভাঙা UI নেই

### D. ডকুমেন্টেশন
- [ ] বড় আর্কিটেকচার পরিবর্তন হলে `docs/` আপডেট
- [ ] পরের কাজকারীর জন্য সংক্ষিপ্ত নোট (PR body বা SIGN-OFF)

### E. সাইন-অফ
- [ ] কী করা হয়েছে, কী বাকি — এক লাইনে লেখা
- [ ] পরিষ্কার করে এসেছে বলে নিশ্চিত

---

## 3. কে মানবে

| কে | দায়িত্ব |
|----|--------|
| মানুষ (মোশাররফ) | নিজে বা এজেন্টকে নির্দেশ দেবে |
| Grok / ChatGPT / অন্য AI | কাজ শেষে এই চেকলিস্ট চালাবে |
| মোশাররফ Core | ভবিষ্যতে অটো রিমাইন্ডার / হেলথ চেক |

---

## 4. যা করা যাবে না

- কাজ ফেলে অপরিষ্কার ব্রাঞ্চ রেখে চলে যাওয়া
- ফেইল করা টেস্ট রেখে “পরে ঠিক করব” বলে চলে যাওয়া
- temporary ফাইল main-এ রেখে দেওয়া
- একই কাজের জন্য অসংখ্য ডুপ্লিকেট ব্রাঞ্চ জমানো

---

## 5. যাচাই টুল

রিপোতে স্ক্রিপ্ট আছে:

```bash
python scripts/cleanup_check.py
```

এটা বলে দেবে:
- সন্দেহজনক temporary ফাইল আছে কিনা
- বেসিক কন্ট্রাক্ট ঠিক আছে কিনা

কাজ শেষে এই স্ক্রিপ্ট চালানো ভালো অভ্যাস।

---

## 6. সংক্ষিপ্ত নিয়ম (মুখস্থ)

```
কাজ করো → টেস্ট পাস → মার্জ → পরিষ্কার → সাইন-অফ → চলে যাও
```

পরিষ্কার না করে চলে গেলে কাজ অসম্পূর্ণ।
